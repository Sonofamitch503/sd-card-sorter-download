# SD Card Sorter

Copy photos and videos off your SD cards into project folders, checked and backed up, so you can safely wipe the card.

**Windows only.** [Download SD Card Sorter](https://github.com/Sonofamitch503/sd-card-sorter-download/releases/latest/download/SD-Card-Sorter.zip) (125 MB)

1. Right-click the zip and choose Extract All.
2. Open the extracted folder and double-click `SD Card Sorter.exe`.
3. If Windows says "Windows protected your PC", click "More info", then "Run anyway".
